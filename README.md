# HGNN-TC

Code for **"Interpretable prediction of thermal conductivity in solid-solution alloys via optimized heterogeneous graph neural networks"**.


## Usage

```bash
python final_train.py \
  --feature_attributed_gnn_data_dir <FA_graph_data_dir> \
  --text_attributed_gnn_data_dir <TA_graph_data_dir> \
  --save_dir results
```
